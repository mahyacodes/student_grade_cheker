# student_grade_cheker
A simple python program to calculate and check student grades.
#What it does
-Takes a student's name and three grades as input
-Calculates the average of the three grades
-Returns a status: "very good", "good", "pass", or "Failed" based on the average
-Displays a formatted report with the student's name, average, and status
#How to run
Make sure you have Python installed
Run the file:
python sep.py
Enter the requested information when prompted
